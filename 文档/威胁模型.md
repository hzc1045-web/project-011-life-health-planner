# 威胁模型

## 保护对象

- 健康和生活画像、计划、日历、药物、预算与执行反馈。
- DeepSeek/AI小站 API 密钥、设备配对令牌、数据库密钥和备份恢复密码。

## 主要威胁与控制

| 威胁 | 控制 |
| --- | --- |
| APK 或仓库泄漏 API 密钥 | 两家密钥分离并分段写入 Windows Credential Manager；构建和提交前扫描。 |
| 未经知情同意切到第三方 | 默认 DeepSeek 官方；AI小站仅允许手动确认切换，手机持续显示当前接收方；每次 AI 请求携带已确认的提供商 ID，不匹配时在调用模型前拒绝。 |
| 未授权设备调用中转端 | Tailscale 来源限制、一次性配对码、设备令牌、时间戳和请求 nonce。 |
| 请求重放 | Bearer 令牌、设备级 nonce 缓存和时间窗口校验。 |
| AI 输出错误或越权 | JSON Schema、本地硬约束、风险门和确认页。 |
| 日历误修改 | 只管理应用创建且已记录 ID 的事件。 |
| 手机丢失 | SQLCipher、Keystore、系统生物识别或设备凭据。 |
| 电脑备份泄漏 | 手机端 AES-256-GCM 加密；恢复密码不发送到电脑。 |
| 日志泄漏健康内容 | 结构化元数据日志；请求体、响应体和 Authorization 永不记录。 |
| 紧急健康风险被普通建议掩盖 | `urgent` 风险状态阻断规划，显示地区化求助方式。 |

## 剩余风险

- DeepSeek 官方和 AI小站的数据处理分别受其自身政策约束；第三方上游留存无法由本应用控制。
- Root、恶意辅助功能服务或已被攻破的手机/电脑可能绕过应用层保护。
- 首版药物规则不是专业药物数据库，不能替代医生或药师复核。
