# 人生健康规划助手 0.1.0 使用说明

## 安装手机端

1. 在 Android 10 或更高版本手机中开启开发者选项和 USB 调试。
2. 用 USB 连接电脑并在手机上允许这台电脑调试。
3. 双击 `apk/Install-APK.cmd`，看到 `Installation completed` 即完成。
4. 首次启动建立个人画像；没有 Health Connect 时可一直使用手工记录。

## 启动电脑中转

1. 首次使用双击 `windows/Setup-Companion.cmd`。
2. 打开 Tailscale 并在电脑与手机登录同一个 tailnet。
3. 双击 `windows/Set-OpenAI-Key.cmd`，在隐藏输入框中录入官方 OpenAI API 密钥。
4. 双击 `windows/Start-Companion.cmd`；登录 Tailscale 后会自动发布仅 tailnet 可访问的 HTTPS 地址。
5. 双击 `windows/Pair-Device.cmd`，用手机系统相机扫描二维码。二维码十分钟后过期且只能使用一次。
6. 不使用时双击 `windows/Stop-Companion.cmd`。

## 计划闭环

在“目标”添加长期目标，在“健康”手工记录或同步健康指标；到“计划”选择日、周或月周期，先查看本次 AI 发送字段，再生成草案。只有本地校验通过并点击确认后，应用才会写入专属日历和安排提醒。每日在“今日”记录完成状态、难度、精力和备注，这些反馈用于下一周期调整。

## 安全边界

本应用不提供疾病诊断、处方或剂量调整。`urgent` 风险会阻止普通计划生成；紧急情况应直接联系当地急救服务。OpenAI 请求设置 `store:false`，但官方 API 默认仍可能保留最长 30 天的滥用监控日志，详见 https://developers.openai.com/api/docs/guides/your-data 。
