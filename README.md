# 人生健康规划助手

`Project_011` 是一套仅供个人使用、Android 本地优先的健康与生活规划工具。

## 项目组成

- `代码/android`：Android 10+ 原生 Kotlin 应用。
- `代码/companion`：Windows AI 中转与加密备份服务。
- `文档`：需求、架构、安全、隐私和验收记录。
- `交付物`：签名 APK、Windows 启动入口和最终测试报告。

## 安全边界

- 不提供疾病诊断、处方或药物剂量调整。
- AI 计划在本地校验并经用户确认后才能写入日历。
- 完整健康档案保存在手机；电脑中转不记录 AI 请求正文。
- OpenAI 请求使用 `store: false`，但官方 API 默认仍可能保留最长 30 天的滥用监控日志。

详细说明见 [文档/项目说明.md](文档/项目说明.md)。

可安装 APK、双击入口和当前验收结果位于 [交付物](交付物)。
