# 恢复说明

## 恢复手机数据

1. 在旧手机设置中输入至少 10 个字符的恢复密码并执行“备份”。密码不会保存或上传。
2. 在新手机安装同一应用并完成电脑配对。
3. 输入完全相同的恢复密码，点击“恢复”。
4. 恢复后重新授权 Health Connect、日历和通知。旧手机的日历事件 ID 不会恢复到新手机。

错误密码或被篡改的密文会在写入数据库前失败，不会以错误内容覆盖本地数据。电脑备份目录位于 `%LOCALAPPDATA%\LifeHealthPlannerCompanion\backups`，其中只有加密信封。

## 签名与升级

发布密钥位于 `%LOCALAPPDATA%\LifeHealthPlannerSigning\release.jks`，签名密码位于 Windows Credential Manager 的 `LifeHealthPlannerSigning/release-keystore` 项。两者都不在项目、APK 日志或 Git 中。保留该 Windows 用户配置后，可双击项目的 `代码/scripts/Build-Release.cmd` 构建同签名升级包。

若发布密钥丢失，无法用新版本覆盖安装现有 APK；只能卸载后重新安装并从加密备份恢复数据。
