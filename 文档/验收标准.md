# MVP 验收标准

## Android 主流程

- Android 10+ 可安装签名 APK，首次启动显示中文引导。
- 完成画像后可以查看今日、计划、目标、健康和 AI 五个页面。
- Health Connect 缺失或拒绝授权时允许手工录入并保持可用。
- 读取已有日历忙碌时段；仅在确认后写入应用专属日历。
- 完成、部分完成、跳过和改期会进入下一轮复盘上下文。

## AI 与安全

- 未配对、令牌无效、请求过期或 nonce 重复时中转端拒绝请求。
- AI 请求明确设置 `store=false`，日志中无请求正文、响应正文和 API 密钥。
- 计划 JSON 不符合 Schema、发生时间冲突或触发紧急风险时不得提交日历。
- 电脑离线时已有计划、提醒和手工记录正常工作。

## 备份恢复

- 手机生成加密信封并上传到电脑；电脑文件不含可识别明文。
- 使用正确恢复密码可在全新安装中恢复，错误密码必须失败且不破坏现有数据。

## 交付

- `交付物/apk` 包含 release APK 和 SHA-256。
- `交付物/windows` 包含启动、停止、配置和健康检查入口。
- 测试报告记录自动化结果、真机限制和需要用户完成的步骤。
